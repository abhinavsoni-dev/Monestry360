# Monestry360 — Heritage Trip Planner & Discovery Platform

A web platform that expands digital access to cultural heritage destinations, helping users discover, plan, and manage heritage trips across regions.

## Tech Stack
- Python
- Django
- MySQL
- Bootstrap

## Features
- Heritage site discovery with regional filtering
- Trip itinerary management
- Booking and calendar integration
- Archive and monastery listings

## How to Run

1. Clone the repository
   git clone https://github.com/abhinavsoni-dev/monestry360.git

2. Install dependencies
   pip install -r requirements.txt

3. Apply migrations
   python manage.py migrate

4. Run the server
   python manage.py runserver

5. Open http://127.0.0.1:8000 in your browser
